## 1.0
Вкладка "File"
(Ее функции)
Посмотрите, есть кнопка "Open". Она предназначена для открытия файлов. Нажмите на нее и перед вами откроется окно проводника. Там нажмите по файлу для открытия.
*Программа находиться в раннем доступе. Можно ожидать ошибок о которых прошу вас сообщить. Спасибо!*
